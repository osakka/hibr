# 0030 — Text direction and shaping come from one Unicode version, in a module

Status: accepted

## Context

A terminal draws one character per cell, left to right, and does no
shaping of its own. Arabic needs joining forms chosen per letter, and any
right-to-left script needs the Unicode Bidirectional Algorithm (UAX #9)
to put mixed text in display order. Some terminals apply bidi themselves;
Blit, which draws hibr straight to the screens, does not (Gitea #68).

hibr's width table was written by hand, records no Unicode version and is
incomplete. A second hand-written set of tables would drift from it.

## Decision

The `uni` module holds the bidi algorithm, Arabic shaping, mirroring and
display widths, every table generated by `tools/unigen.py` from one
version of the Unicode Character Database (15.1.0 now), named in the
output and answered by `uni version`. The conformance suites ship beside
it, gzipped in `tests/uni`, from the same version:

- `tests/uni_bidi.py` runs every case of BidiTest (770,241, with each
  paragraph direction asked for) and BidiCharacterTest (91,707, with
  bracket pairs), and passes all of them;
- `tests/uni_shape.py` compares display order and shaping with GNU
  FriBidi, case by case, since shaping has no conformance suite.

Shaping is what a cell grid needs: each Arabic letter its isolated,
initial, medial or final presentation form, joining only within one
embedding level and across transparent marks, and lam-alef as one
ligature cell. Display order keeps a combining mark after its base, so a
cell grid draws it on the right character. Mirrored characters take their
mirror at a right-to-left level.

It is a module, not core: a script that never meets right-to-left text
never loads it. The core line editor will reach it through `hibr_require`
when it meets such a character (phase 2).

## Consequences

- The module is 56 kB and only a script that loads it pays for it.
- Regenerating means `tools/unigen.py fetch VERSION build/ucd`, `gen`, and
  replacing the suites in `tests/uni` from the same download -- never one
  without the others.
- Shaping is checked against FriBidi 1.0.8 on this machine; a letter
  newer than FriBidi's own Unicode version cannot be checked that way.
- `src/edit.c`'s hand-written width table is replaced by these in phase 2.
